# HPC / Slurm Execution Rules

- **CRITICAL**: We are operating directly on an HPC cluster login node.
- **NEVER** run computationally heavy Python scripts directly using `python <script.py>` or `python3 <script.py>` in the terminal.
- **Always** execute compute-intensive tasks, data processing, model training, or benchmarks via Slurm using `srun`.
- **Default srun template**:
  `srun --p compsci-gpu --gres gpu:1 python <script.py>`
  Example:
  `srun -p compsci-gpu --gres gpu:1 python -m ppo.ppo_exact_td --env-ids FourRooms-misc --n-seeds 1 --config '{"LR": 0.01}'`
- Only lightweight operations (e.g., `python --version`, inspecting a package, running quick unit tests lasting under 2 seconds) are permitted directly on the login node.
